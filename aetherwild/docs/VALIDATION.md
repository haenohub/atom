2026-10-21 · AETHERWILD v0.1.0 · Node.js 24.19.0 · Three.js 0.180.0 · Vite 7.1.12

## 재현 가능한 설치

다음 순서의 전체 설치 절차를 현재 클라우드 환경에서 실행해 통과했다. `npm ci`는 기존 lockfile을 변경하지 않는다.

```bash
cd /workspace/atom
export npm_config_cache=/workspace/.cache/npm
npm ci --no-audit --no-fund
npm test
npm run build
```

클라우드 설정 초안에 동일한 `install_script`와 개발/플레이 서버의 시작·준비 확인 절차인 `start_skill`을 저장했다. 초안 저장은 환경 게시나 GitHub 커밋·푸시를 의미하지 않는다. 환경 설정에서 검토·저장 후 게시해야 재사용할 환경 스냅샷에 반영된다. 게시 후 새 작업에서의 복원은 아직 검증하지 않았다.

## 실제 Chromium: 플레이 흐름 14개 통과

`python3 tests/browser_smoke.py`의 최종 결과: **14개 통과, JavaScript 오류 0**.

실제 WebGL 렌더링과 세 직업 선택, 마법사 새 게임/Pointer Lock, 키보드 이동·점프·착지, E 채집, 상자 일회성 보상, 화염구 투사체 처치와 드랍, 마나 제한, UI 제작/장비 장착, 야영지 전직 제한/성공, 9종 도감/지도, 새로고침 후 이어하기, 사망/부활을 확인했다.

테스트에서는 도달 시간이 긴 상태를 준비하기 위해 **개발 서버에서만 제공하는 접근점**으로 위치·레벨·재료를 준비했다. 따라서 레벨 1부터 20까지 자연스럽게 성장하는 전체 플레이 시간이나 장기 밸런스를 검증한 것은 아니다. 이동·채집·발사·제작·전직·이어하기 등의 행동은 실제 입력과 UI를 통해 수행했다.

초기 검사에서 느린 프레임 사이에 점프 키를 짧게 누르면 입력이 누락되는 문제를 발견했고, 점프 요청을 다음 물리 프레임까지 유지하도록 수정한 뒤 최종 흐름을 통과했다.

## 배포본과 Codespaces 실행

- `npm run build`: 성공. Three.js 포함 단일 JS 번들 약 590kB, gzip 약 159kB. Vite의 500kB 청크 권고는 남아 있으며 빌드 오류가 아니다.
- `bash play.sh 4173`: 빌드된 `dist`를 Python HTTP 서버로 제공하는 절차를 실제 실행했다.
- 해당 배포본을 Chromium에서 로드해 궁수 시작, Pointer Lock, 입력, 소지품과 지도를 확인했다. JavaScript 오류/실패 에셋 요청이 없으며 개발용 접근점이 포함되지 않았다.
- 개발 서버를 재시작한 뒤 Codespaces 형식의 `.app.github.dev` Host 헤더가 HTTP 200, 허용하지 않은 호스트가 HTTP 403인 것을 확인했다. 사용자의 실제 Codespace에 파일을 전송하거나 그 원격 브라우저에서 실행한 것은 아니다.
- ZIP에는 소스, lockfile, 개발 계획과 수치표, 테스트, 빌드된 배포본, 실행 스크립트, 렌더러 라이선스가 포함된다. `node_modules`, Git 내부 정보, 자격 증명은 포함하지 않는다.

## 검증 범위의 한계

Linux Chromium의 소프트웨어 WebGL로 기능을 확인했다. 이는 일반 PC GPU 성능 측정이 아니다. 실제 FPS는 기기·해상도에 따라 달라지며 낮음 품질 설정을 제공한다. 실제 소요 플레이 시간, 모든 월드 경로, 모든 브라우저 조합, 멀티플레이, 모바일 터치는 검증하지 않았다. 이 버전은 PC용 싱글플레이 로우폴리 첫 버전이며 장기 콘텐츠/애니메이션/길찾기 개선은 후속 작업이다.
