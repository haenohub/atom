# AETHERWILD · 에테르와일드 개발 계획

## 목표와 첫 출시 범위
아름다운 자연 속에서 탐험, 전투, 성장, 제작이 이어지는 브라우저용 싱글플레이 1인칭 3D RPG를 만든다. 첫 버전은 하나의 약 640×640m 연속 월드, 최고 20레벨, 세 기본 직업과 여섯 전직으로 구성한다. 서버·계정·상용 외부 에셋은 사용하지 않는다. Three.js는 렌더링 엔진으로만 사용하며 지형, 식생, 캐릭터, 무기, 아이콘, 이펙트와 음향은 프로젝트에서 직접 생성한다. 대형 상용 RPG 수준의 콘텐츠 분량, 멀티플레이, 모바일 터치 조작은 이번 범위 밖이다.

## 제작 순서와 완료 기준
1. **설계 및 규칙**: 직업/스킬, 경험치, 전리품 확률, 제작식 데이터와 순수 게임 규칙 구현. 자동 테스트로 확률 경계·레벨업·재료 소모·전직 조건 검증.
2. **세계와 이동**: 연속적인 높이 함수 기반 숲/호수/고원/설산/화산, 원근 안개·구름·빛·물·절벽·유적 구현. 중력, 지면 접촉, 점프, 수영, 달리기, 낙하 피해, 장애물 충돌 적용.
3. **전투와 성장**: 지형별 몬스터 모델, 순찰/추격/공격/복귀/재생성, 근접 및 투사체 전투. 세 직업의 공격, 레벨별 스킬, 전직 스킬 연결.
4. **탐험과 경제**: 숨겨진 상자, 재생 채집물, 인벤토리/장비, 대장/요리/연금술 제작, 탐험 목표 연결.
5. **플레이 흐름**: 직업 선택, HUD, 지도, 도감, 제작/인벤토리, 사망/부활, 로컬 저장, 설정과 조작 설명.
6. **검증과 실행**: 규칙 테스트, 프로덕션 빌드, Chromium WebGL 브라우저 스모크 테스트. README에 Codespaces 및 로컬 실행법 기록.

## 세계 설계
| 지역 | 권장 레벨 | 지형과 역할 |
|---|---|---|
| 새벽의 숲 | 1–4 | 야영지, 완만한 언덕, 꽃밭, 나무, 초보 채집 |
| 거울 호수 | 4–7 | 낮은 분지, 물가와 섬, 수영, 버섯과 수정 |
| 바람 고원 | 7–11 | 융기한 능선, 바위길, 고대 유적, 광석 |
| 은빛 설산 | 11–15 | 높은 봉우리와 눈, 좁은 산길, 희귀 약초 |
| 잿불 황무지 | 15–20 | 붉은 분화구와 검은 암석, 고급 재료, 최종 수호자 |

지역은 로딩 없이 연결한다. 경사는 걷기 가능한 길과 가파른 면을 구별하며, 나무와 큰 바위는 원형 충돌체를 둔다. 상자 위치와 채집물은 결정적 시드로 배치하고 저장한다. 지도는 고저·지역·플레이어 위치·야영지를 표시한다.

## 직업과 스킬
공통: 좌클릭 기본 공격, Q 회복약, E 상호작용, Shift 달리기, Space 점프. 숫자 1–5 스킬. 스킬은 레벨 1/4/7/10/15에 해금된다. 10레벨 이상 야영지에서 한 번 전직한다.

| 기본 직업 | 1 / 4 / 7레벨 | 2차 전직 | 10 / 15레벨 |
|---|---|---|---|
| 전사 | 회전베기 / 돌진참 / 강철 피부 | 기사 | 성역 / 심판 |
| 전사 | 동일 | 광전사 | 피의 격노 / 대지 분쇄 |
| 궁수 | 관통화살 / 서리화살 / 치유의 바람 | 레인저 | 화살비 / 폭풍 사격 |
| 궁수 | 동일 | 그림자사냥꾼 | 독화살 / 암살 표식 |
| 마법사 | 화염구 / 얼음 파동 / 비전 회복 | 대마법사 | 운석 / 비전 폭풍 |
| 마법사 | 동일 | 원소술사 | 번개 사슬 / 정령의 축복 |

레벨마다 기본 공격력/체력/마나가 성장한다. 장비 공격력과 방어력, 버프, 마나, 재사용 대기시간이 실제 전투에 반영된다. 스킬별 수치는 `src/data.js`를 정본으로 사용하고 게임 내 스킬 창에 표시한다.

## 몬스터와 전리품
각 항목은 독립 확률 추첨이다. 따라서 한 처치에서 복수 전리품이 나오며 행 확률 합계가 100%일 필요는 없다. 골드와 경험치는 처치 시 별도 지급한다. 모든 몬스터는 지역 내에서만 추격하고 약 40초 후 재생성한다.

| 몬스터 | 레벨 | 전리품(개별 확률) |
|---|---|---|
| 이끼 슬라임 | 1 | 점액 100%, 야생초 35%, 회복약 8% |
| 숲 늑대 | 3 | 가죽 100%, 생고기 65%, 송곳니 25% |
| 호수 정령 | 5 | 물의 정수 75%, 수정 35%, 마나약 15% |
| 가시 멧돼지 | 7 | 가죽 100%, 생고기 80%, 철광석 25% |
| 바위 골렘 | 9 | 철광석 100%, 수정 45%, 고대 파편 20% |
| 서리 늑대 | 12 | 서리꽃 65%, 가죽 100%, 물의 정수 40% |
| 수정 수호자 | 15 | 수정 100%, 고대 파편 45%, 별의 결정 15% |
| 잿불 비룡 | 18 | 불의 정수 100%, 비늘 60%, 별의 결정 25% |
| 고대 수호자 (우두머리) | 20 | 고대 파편 100%, 별의 결정 100%, 비늘 80%, 세계수의 심장 25% |

드랍 수량, 공격력, 체력, 공격 간격 등 실제 값은 `src/data.js`에 둔다. 도감에서 전체 확률을 확인할 수 있다. 상자는 한 번 개봉하며 고급 지역일수록 보상이 커진다. 채집물은 90초 후 재생한다.

## 제작과 탐험
- 대장: 철/가죽/수정/정수로 무기와 방어구 제작. 직업별 무기 제한, 장비 교체와 능력치 적용.
- 요리: 고기/버섯/약초로 즉시 체력 회복과 일정 시간 공격력 강화 음식을 제작.
- 연금술: 약초/물의 정수로 회복/마나약, 희귀 재료로 강화 영약 제작.
- 휴대 제작 가능. 전직은 야영지에서만 가능. 재료가 부족하면 제작하지 못하며 원자적으로 소모한다.
- 탐험 목표: 첫 처치 → 채집 → 제작 → 10레벨 전직 → 최종 수호자 격파. 각 목표는 한 번 보상한다.

## 저장과 검증
브라우저 localStorage에 캐릭터, 레벨, 경험치, 인벤토리, 장비, 진행, 열린 상자, 위치를 버전과 함께 저장한다. 주기적/패널 조작/페이지 이탈 시 저장하며 손상 데이터는 복구 가능한 오류로 처리한다. 서버 동기화는 없다. 규칙은 Node 테스트로, 3D 렌더링과 입력·UI는 실제 Chromium으로 검증한다. 프레임률은 기기에 따라 달라지므로 그래픽 품질 설정을 제공한다.
