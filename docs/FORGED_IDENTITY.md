## 캔슬 전투 규칙

기존에는 전사 공격 모션이 끝날 때까지 다른 공격/스킬 입력을 막았다. 이제 입력을 받는 즉시 새 동작으로 교체한다. 이전 공격이 타격 시점에 도달하기 전에 취소되면 그 타격은 제거한다. 이미 발생한 피해는 되돌리지 않는다. 취소해도 이미 사용한 마나와 스킬 재사용 시간은 환불하지 않으며, 마나·레벨·재사용 조건을 충족하지 못한 입력은 진행 중인 동작을 바꾸지 않는다.

공격마다 검을 움직이는 준비/타격/회복 구간은 유지한다. 따라서 입력 사이의 강제 대기는 없지만, 타격 전에 계속 기본 공격을 취소하면 이전 공격의 피해가 발생하지 않는다. 메뉴·마우스 해제에서는 게임 진행을 정지한다.

## 장비·능력치

- **무기 / 상의 / 투구 / 장갑 / 신발**. 소유 아이템을 클릭하여 장착하고 장착 슬롯을 클릭하여 해제한다. 무기는 기본 무기를 유지하므로 해제하지 않는다. 장비는 소모되지 않는다.
- 신규 캐릭터는 직업별 기본 방어구 4개를 착용한다. 직업별 기본 세트는 Lv.1, 영웅 세트는 Lv.12이며 제작으로 획득한다. 다른 직업의 전용 장비는 장착할 수 없다.
- 전사: 철엽 수호자 → 여명 성기사. 궁수: 숲그늘 추적자 → 비취 사슴왕. 마법사: 밤하늘 학자 → 성좌 현자.
- 레벨당 **3포인트**. 전사=힘, 궁수=민첩, 마법사=지능이 주 능력치다. 장비와 배분의 주 능력치 1당 공격력 +1.5. 체력은 HP·방어, 지능은 MP·마나 회복, 민첩은 치명타·이동속도, 힘은 치명타 배율에도 반영한다.
- 무료 초기화는 사용한 포인트만 돌려준다. 장비 해제·초기화로 최대 HP/MP가 줄면 현재 값도 상한에 맞춰 내린다. 배분·재장착으로 즉시 회복하는 기능은 없다.

정확한 보너스·재료·확률은 [CONTENT_REFERENCE.md](CONTENT_REFERENCE.md)에 코드에서 생성한다.

## 시점과 귀환

**F1**로 1인칭/3인칭을 전환한다. 게임의 이동·저장·상호작용·공격 기준점은 플레이어 눈 위치로 유지하고, 3인칭에서 렌더링용 카메라만 뒤로 이동한다. 지형과 나무/바위 등의 충돌체를 만나면 카메라를 앞으로 당긴다. 너무 가까워져 캐릭터 안에 들어가면 전신 모델을 숨긴다. **Alt+마우스**로 캐릭터 주위를 둘러보고 놓으면 뒤쪽 시점으로 돌아온다.

귀환 주문서는 바닥 주머니에서 수거해야 한다. **R** 또는 가방의 주문서를 클릭하면 한 장을 소모하여 새벽 야영지로 이동한다. 다른 몬스터의 체력·재생 시간, 남겨 둔 전리품과 퀘스트는 초기화하지 않는다. 사용 가능한 주문서가 없으면 이동하지 않는다. NPC가 있는 처음 야영지가 이 버전의 귀환 마을 거점이다.

## 원화와 재질

모두 프로젝트용으로 새로 생성했다. 외부 캐릭터·스톡 아이콘·스킬 팩은 사용하지 않는다. 3D 모델/모션/이펙트는 직접 작성한 코드이며, 생성한 이미지가 실제 게임의 재질과 UI에서 사용된다.

## 저장 호환과 실행

기존 v0.1–v0.3 저장의 직업·레벨·인벤토리·무기/갑옷·NPC 의뢰·미수거 전리품을 유지한다. 기존 저장의 신규 장비 슬롯은 비어 있으며 제작/장착할 수 있다. 기존 레벨로 얻은 미배분 능력치 포인트가 열리고 최초 시점은 1인칭이다. v0.4 저장부터는 모든 슬롯·배분·시점 설정을 복원한다.

Codespaces에서 실행 중인 서버를 Ctrl+C로 종료한 뒤:

```bash
git fetch origin
git switch codex/aetherwild-v0.1.0
git pull --ff-only
bash play.sh
```

Ports의 5173 페이지를 열고 새로고침한다. ZIP은 압축을 푼 `aetherwild` 폴더에서 `bash play.sh`로 실행한다. 같은 브라우저와 주소를 사용하면 기존 자동 저장을 이어서 사용할 수 있다.

이 버전은 브라우저용 절차적 3D 게임이며, 생성된 원화와 3D 모델의 정밀도가 동일하지는 않다. 실사 스캔 캐릭터나 모션 캡처를 사용하지 않는다. 검증 범위와 실행 결과는 [VALIDATION.md](VALIDATION.md)에 기록한다.
