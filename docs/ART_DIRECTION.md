# AETHERWILD v0.2 — Wilderness & Combat

## 시각 방향

기존의 단색 로우폴리 표현에서 자연 재질과 빛의 반응을 표현하는 방향으로 변경했다. 외부 스톡 그래픽 팩은 사용하지 않았다. 이 버전도 브라우저용 절차적 3D 게임이며, 실사 촬영·스캔 기반의 상용 게임 그래픽을 재현했다고 주장하지 않는다.

### 새로 생성한 이미지

- `public/assets/forest-floor.png`: 이 프로젝트를 위해 새로 생성한 숲 바닥 알베도. 이끼, 짧은 풀, 흙, 잎 조각, 자갈을 포함한 정사영 재질 이미지. 생성 도구: OpenAI 이미지 생성.
- `public/assets/ability-icons.png`: 이 프로젝트를 위해 새로 생성한 5×5 능력 아이콘 아틀라스. 칼날, 방패, 정령, 원소, 화살 종류, 물약, 가방, 나침반 등 25개. 생성 도구: OpenAI 이미지 생성.
- 원본 이미지는 전체 파일 그대로 사용한다. 아이콘은 CSS sprite 좌표로 선택하며 이미지 파일을 편집해 잘라내지 않았다.

### 코드로 새로 만든 그래픽

- `src/art.js`: 나무껍질·바위·흙·가죽의 색상 및 법선 맵, 잎과 풀의 알파 실루엣, 바람 셰이더.
- 지형: 원본 숲 재질, 길의 흙, 경사면의 암석, 고지대 눈, 황무지 재질을 월드 좌표와 고도·경사로 합성.
- 숲: 실제 가지 구조, 얇은 잎 카드와 풀 군락. 기존의 불투명한 구형 수관과 원뿔 풀을 대체.
- 하늘: Three.js Sky의 대기 산란, 반투명 구름, 환경 반사와 안개.
- 물: 물결 변위, 움직이는 법선, 거칠기·반사·클리어코트.
- `src/weapons.js`: 베벨 칼날, 목재 리커브 활, 시위, 화살촉·깃털, 지팡이, 손과 장갑. 활은 당기는 정도에 따라 실제 메시와 시위 위치가 변한다.
- `src/effects.js`: 지형에 맞춰 붙는 문양, 범위 미리보기, 불꽃 입자, 서리 결정, 운석, 번개, 비전 장과 화살 궤적.
- `src/icons.js`: 아틀라스 선택과 자원용 SVG 아이콘.
- `public/assets/interface-grain.svg` 및 `src/style.css`: 새 금속·가죽 계열 UI 표면, 프레임, 상태창, 핫바, 선택 상태, 활 당김 게이지.

## 궁수 조작 및 자원 규칙

1. 좌클릭을 누르면 활을 당긴다. 누른 순간에는 발사하지 않는다.
2. 1.15초에 최대 당김에 도달하며 계속 누르면 유지한다. 마우스를 놓으면 한 발 발사한다.
3. 당김에 따라 위력은 기본 공격의 38%→160%, 초기 속도는 23→72m/s로 증가한다. 짧게 당기면 편차가 커진다. 화살은 중력 9.81m/s²를 적용한다.
4. 공격 화살 스킬의 숫자 키는 **다음 한 발의 종류를 변경**한다. 장전할 때는 마나·쿨다운을 소비하지 않는다. 동일 키를 다시 누르면 일반 화살로 돌아간다.
5. 발사할 때 조건을 다시 확인하고 마나를 소모하며 쿨다운을 시작한다. 그 한 발 뒤에는 일반 화살로 복귀한다.
6. 치유의 바람은 즉시 사용하는 회복 스킬이다. 레인저의 화살비도 화살에 장전하며, 적중 지점을 중심으로 범위 피해를 준다.
7. 메뉴, 마우스 고정 해제, 창 포커스 상실 중에는 당김을 취소하고 화살을 발사하지 않는다.

## 마법사 조작 및 범위 판정

1. 공격 스킬의 숫자 키를 누르면 지면 범위 미리보기를 켠다. 이 단계에는 마나·쿨다운 소비가 없다.
2. 지면을 겨누고 좌클릭하면 확정한다. 범위 밖·물 위·지면을 가리키지 않는 경우에는 시전하지 않는다.
3. 우클릭 또는 동일 스킬 키를 다시 눌러 취소할 수 있다. 취소 비용은 없다.
4. 기본 공격도 지면 반경 2.2m의 비전 파동이다. 마법사 공격 스킬과 기본 공격은 비행 투사체를 만들지 않는다.
5. 불꽃의 장: 반경 7m, 0.4초 준비 후 3초 동안 6회, 합계 공격력 280%. 서리 결계: 반경 9m, 0.25초 후 공격력 180%와 빙결 4초.
6. 운석 낙하, 비전 폭풍, 뇌우의 장 역시 지정 지면 중심의 범위다. 운석의 낙하 메시와 번개는 시각 효과이며 이동 투사체 충돌 판정과 분리된다.
7. 각 틱마다 실제 현재 위치로 범위를 판정한다. 수평 거리와 높이 차를 함께 검사한다. 범위 밖 적에게 피해를 주지 않는다.
8. 비전 회복과 정령의 축복은 즉시 적용되는 자신 대상 보조 스킬이다.

## 성능과 업데이트

식생은 인스턴싱·구역별 배치로 묶고, 먼 채집물·몬스터·풀은 거리별로 제외한다. 하드웨어에 따라 높은 품질에서 그림자를 사용하며 소프트웨어 렌더러는 낮음으로 자동 선택한다. 설정에서 직접 바꿀 수 있다. 잎/풀의 발광 재질은 강한 역광에서의 투과광을 근사하기 위한 약한 보조 조명이다.

빌드할 때 `dist/build-meta.json`에 소스·에셋의 해시를 기록한다. `play.sh`는 Node가 있을 때 이를 비교하므로, 같은 Codespaces에서 `git pull` 후 실행하면 오래된 빌드가 남아 있더라도 자동으로 다시 빌드한다. 저장 데이터 형식과 슬롯 키는 유지해 v0.1의 캐릭터를 불러올 수 있다.
