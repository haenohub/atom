# v0.6 — Forged Forms

## 제작 사양

모든 장비는 아이템 ID별 외형 키를 갖는다. 무기 9종, 공용 갑옷 3종, 직업 방어구 24종의 착용 모델을 구분한다. 투구·장갑·신발의 등급은 각 슬롯에서 독립적으로 결정한다. 1인칭 장갑·무기와 3인칭 전신에 즉시 반영하고 해제 시 기본 의복으로 돌아간다.

프로필 원화 `public/assets/portraits.png`를 기준으로 사람 체형은 약 7.6등신, 어깨·허리·팔꿈치·손목·무릎이 구분되는 형태로 설계한다. 전사: 넓은 흉곽·붉은 망토·금속 장식, 궁수: 남성 체형·녹색 후드·가죽 조끼·화살통, 마법사: 여성 체형·긴 흑발·남색 별무늬 로브·휘어진 모자. 레아: 갈색 묶은 머리·청록 의상·은빛 어깨 갑옷, 엘리아: 적갈색 땋은 머리·녹색 꽃 후드, 토렌: 넓은 체형·회갈색 수염·가죽 앞치마.

전사 기본 공격은 좌횡베기·우대각베기·수직 내려찍기 세 자세를 순환한다. 회전베기는 몸통을 회전하고, 심판·대지 분쇄는 양팔을 들어 강타한다. 돌진참은 0.38초 동안 힘을 모은 뒤 실제 이동 컨트롤러로 돌진한다. 공격 캔슬 시 발동 전 타격을 제거한다. 마법사는 구체 공격 시 지팡이를 밀어내고, 범위 마법은 지팡이를 높이 들어 올린 뒤 풀어낸다. 궁수는 활 당김과 즉시 광역 사격을 별도 자세로 표시한다.

마법사 텔레포트의 재사용 대기는 0초이며 매회 MP 15와 장애물 판정은 유지한다. 그림자사냥꾼 10레벨 독화살을 삭제하고 **그림자 화살 폭풍**을 추가한다: 즉시 전방 10m 지점 반경 8m에 공격력 380%, MP 25, 재사용 10초. 15레벨 암살 표식은 유지한다. 기존 전직 저장은 로드 즉시 새 스킬로 연결된다.

## 몬스터 재디자인

몸통 표면 외에 눈꺼풀·턱선·치아·코·갑각·갈기·날개뼈·풍절깃·발톱을 해부 구조에 맞게 제작한다. 비룡은 가늘어진 긴 주둥이, 경사진 눈꺼풀과 세로 동공, 분리된 치열, 관자뿔, 등줄기 비늘, 손가락 사이에 펼쳐진 부채형 익막을 사용한다. 바위 계열은 각진 석판·침식 모서리·틈새 룬을 갖는다. 같은 해부 계열도 종별 비율과 표면을 달리한다.

신규 5종은 가시 낫사마귀(숲 Lv.6), 심연 유리뱀(호수 Lv.10), 월광 스핑크스(고원 Lv.14), 용암 갑주거미(화산 Lv.16), 폭풍 왕관조(설산/구름 정원 Lv.19). 각 종의 서식지·실루엣·공격 준비·이동 자세·전리품은 도감 데이터에 연결한다. 전체 17종을 실제 월드에 배치한다.

## 제작/렌더링 보정

- 새 `forged-surfaces.png`: 직접 생성한 갑각·풍절깃·날카로운 용 비늘·별무늬 로브 2×2 재질. 원본 파일을 보존하고 UV/셰이더로 선택한다.
- 미러 타일링으로 동물의 몸을 가로지르던 재질 경계를 완화했다. 인체 단면의 진행 방향과 곡선의 바깥 면 법선을 검사하여 의복·사지·뿔이 안으로 뒤집히는 문제를 수정했다.
- 고정 장식은 관절과 재질별로 합쳐 드로 콜을 줄이고, 실제로 움직이는 뼈대/팔/날개는 별도로 유지한다.
- 모든 17종의 실제 렌더링과 몸체 연결성을 검사한다. 전체 스크린샷은 GitHub `docs/screenshots/v0.6-*`에 보관하고 실행 ZIP에는 핵심 8장을 포함한다.
