# v0.7 — Wind & Shadow

## 조작과 판정

궁수는 **왼손으로 활을 잡고 오른손으로 시위를 당기는 오른손잡이**다. 1인칭에서 시위의 중앙·화살 꼬리·오른손이 함께 오른쪽 뺨 방향으로 이동한다. 3인칭에서도 활은 왼손 뼈대에 부착하고 오른팔이 시위를 당긴다.

| 직업 / 키 | 변경된 행동 |
|---|---|
| 궁수 / 2 | 서리화살 장전 → 좌클릭 유지 후 놓아 발사. 적중한 적을 중심으로 반경 5m의 모든 적에게 220% × 당김 배율 피해와 6초 둔화. 최초 적중 대상도 한 번만 피해를 받으며 지면에만 맞으면 폭발하지 않음 |
| 그림자사냥꾼 / 4 | 지면 범위 선택 → 좌클릭 확정. 바닥으로 활을 쏜 뒤 0.3초 후 지정 반경 8m에서 보라색 화살이 위로 솟아 380% 피해. 사거리 35m, MP 25, 재사용 10초 |
| 그림자사냥꾼 / 5 | 암살 표식 화살 장전 → 당겨 놓아 발사. 첫 적중 뒤 최대 5회 추가 도약, 최대 서로 다른 6마리 적중. 매번 직전 대상의 10m 안에 있는 살아 있는 새 대상을 찾아 실제 화살이 방향을 바꿔 비행. 대상당 900% × 당김 배율, MP 40, 재사용 18초 |
| 레인저 / 4 | 지면 범위 선택 → 좌클릭 확정. 하늘로 활을 쏜 뒤 0.3초 후 지정 반경 8m에 화살비, 450% 피해. 사거리 55m, MP 30, 재사용 13초 |
| 레인저 / 5 | 폭풍 사격 화살 장전 → 당겨 놓아 발사. 중력 없이 직선으로 최대 60m 비행하며 경로 반경 6m의 적 모두에게 각각 한 번씩 750% × 당김 배율 피해. 회전하는 바람이 살아 있는 적을 중심으로 최대 8m/s로 끌어당김. MP 40, 재사용 16초 |
| 마법사 / 좌클릭·마법 | 지팡이와 오른팔을 바깥에서 안으로 휘두르는 자세. 범위 마법의 지팡이 들어올리기와 함께 적용 |
| 마법사 / Shift | 최대 6m 텔레포트, MP 15, **재사용 대기 0.5초** |

범위 지정은 우클릭 또는 같은 숫자 키로 취소한다. 선택과 취소에는 마나·쿨타임을 소모하지 않으며, 유효한 땅에서 좌클릭으로 확정할 때 지불한다. 화살 장전 모드와 지면 선택 모드는 서로 전환되고, 전환 중이던 활 당김은 안전하게 취소한다.

## 발사와 이펙트 시간

두 범위 사격은 0.45초 준비·발사 동작을 가진다. 발사 시 실제 장식 화살이 각각 아래/위로 날아가며, **그 발사 시점에서 0.3초 뒤**, 즉 확정 후 0.75초에 지정 범위 피해와 화살 효과가 시작한다. 방향을 바꾸거나 잠깐 메뉴를 열어도 이미 확정한 범위는 바뀌지 않고, 메뉴에서는 전투 시간이 멈춘다. 발사 전까지 다른 사격으로 동작을 덮어쓰지 않는다.

그림자 화살은 지면 아래에서 상승하고 화살비는 위에서 하강한다. 화살촉과 깃을 갖춘 32개 화살을 순차 배치한다. 폭풍 화살은 직접 만든 나선형 바람 메시와 기존 전투 원화 텍스처를 사용해 회전한다. 새로운 외부 그래픽 팩은 추가하지 않는다.

## 충돌과 저장 호환

기존 관통화살의 연속 구간 판정과 중력은 유지한다. 서리 폭발은 주변 대상을 별도로 순회하여 최초 대상에 피해를 중복 적용하지 않는다. 암살 표식은 적중 ID를 보관해 재적중을 막고, 사망한 대상을 제외하며 도약마다 사거리와 남은 비행 시간을 갱신한다. 폭풍은 지나간 구간 전체를 검사하므로 빠른 화살도 적을 건너뛰지 않는다. 끌어당김은 벽·급격한 고도 변화·물·구름섬 가장자리를 넘기지 않는다.

기존 캐릭터와 전직 저장은 같은 직업/전직 데이터를 통해 새 스킬로 이어진다. 장비 36종, 몬스터 17종, 세이브 5칸과 테스트 경험치/장비 드랍 5배는 유지한다. 플레이는 [웹 주소](https://haenohub.github.io/atom/)에서 배포 완료 후 새로고침하면 된다.
