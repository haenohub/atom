## 생물 디자인 사양

## 지역별 판타지 언어

- 새벽의 숲: 푸른 빛을 내는 세계수 뿌리와 반딧불의 원.
- 거울 호수: 수면 위에 떠 있는 역중력 물의 고리와 수정 기둥.
- 바람 고원: 부유하는 암편과 바람을 모으는 회전 천문 고리.
- 은빛 설산: 푸른 수정 아치와 움직이는 오로라 장막.
- 잿불 황무지: 빛나는 용암맥과 불씨를 토하는 흑요석 첨탑.
- 구름 정원: 잔디·꽃이 덮인 부유섬, 구름 아래로 뻗는 암석 뿌리, 황금 풍경과 등반용 줄. 야영지 동쪽의 차원문으로 진입한다.

## 테스트 배율과 저장

경험치 보상은 처치·채집·상자·탐험 달성·NPC 의뢰 모두 기본값의 5배. `gainXp`는 내부의 원시 경험치 계산이며 실제 보상은 `awardXp`를 통한다. 장비는 몬스터별 기본 드랍 테이블을 새로 정의하고 장비에만 5배를 적용한다(최대 100%). 재료·소모품·귀환 주문서 확률은 그대로. 도감에는 적용 확률과 기본 확률을 함께 표시한다.

저장 칸 1~5는 독립적이다. 구버전 단일 저장은 최초 실행 때 1번으로 복사하고 원본은 남긴다. 선택 칸과 실제 플레이 중인 칸을 구분하여 다른 캐릭터를 덮어쓰지 않는다. 시작 화면에서 칸을 고르고 새 여정/이어하기를 누른다. 같은 칸의 새 여정은 덮어쓰기 확인을 거친다.

## 조작과 이동 수치

- 전사: Shift 0.18초 대쉬, 4.5m, 기력 24, 재사용 1.2초. 기본 공격과 스킬 캔슬 유지.
- 마법사: Shift 최대 6m 텔레포트, MP 15, 재사용 2.5초. 기본 공격은 속도 29m/s·거리 48m의 단일 적중 마력구체이며 중력은 받지 않는다.
- 궁수: Shift 달리기 유지. 좌클릭을 당기는 동안 중력 9.81을 적용한 궤적을 표시한다. 비행 화살의 굵기는 2.2배, 길이는 1.65배. 관통화살·폭풍 사격·암살 표식은 같은 적을 중복 타격하지 않고 통과한다.
- 줄 근처 E로 매달림 → W/S로 초당 4m 오르내림. Space로 뛰어내리거나 E로 놓는다. 끝까지 오르면 섬 위로 안전하게 올라선다.
- 구름 정원 아래로 추락하면 결계가 입구로 돌려보내며 최대 HP의 8%를 기준으로 피해를 준다(방어 계산 적용). 귀환 주문서와 입구 귀환문도 사용할 수 있다.
- 고도·섬·줄 배치의 정본은 `src/sky-layout.js`. 단순 상하 이동이 아니라 다섯 개 실제 점프 구간과 두 등반 구간을 순서대로 연결한다.
