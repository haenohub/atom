# v0.3 · People of the Wilds

## 제작 계획과 구현

전투 동작, 전리품 수거, NPC와 의뢰를 기존 성장·제작 루프에 연결한다. 이전 캐릭터의 레벨·장비·인벤토리를 유지하면서 새로운 진행 필드만 추가한다.

| 요청 | 구현 |
|---|---|
| 전사 기본 공격과 스킬 모션 | 좌우 연속 베기, 회전 베기, 돌진 찌르기, 방어 자세, 버프 발동, 두 전직의 내려찍기 |
| 바닥에 떨어지는 전리품 | 중력·두 번의 작은 바운스·등급 표시를 가진 주머니, E 수거, 아이템과 골드 함께 보관 |
| 몬스터 동작 디테일 | 여섯 체형의 관절 모델을 9종 생물에 적용. 다리·발·머리·턱·꼬리·날개, 숨쉬기·보행·공격 준비·피격·사망 |
| 그래픽 발전 | 독립적인 하늘 색과 태양 광륜, 자연광 보정, 지면 재질 혼합, 고사리, 생물 세부 형상, 모루·작업대·등불, 높은 품질에서 2048 그림자 |
| NPC와 퀘스트 | 야영지 NPC 세 명, 대화·수락·진행·보고·보상, 선행 의뢰와 레벨 조건, 6개 의뢰와 J 기록창 |

## 모션과 전투 판정

전사는 동작의 준비 시간이 지나 실제 휘두르는 시점에 한 번 피해를 준다. 기본 공격은 0.18초, 회전베기는 0.28초, 돌진은 0.2초, 심판·대지 분쇄는 0.42초의 준비 시간이 있다. 방어·격노·성역도 무기를 들어 올린 뒤 0.22초에 발동한다. 동작 중 다른 공격으로 준비 시간을 취소하여 중복 피해를 낼 수 없다. 우클릭 방어는 즉시 적용되며 전용 검 자세를 표시한다. 메뉴에서는 진행 중인 동작이 정지한다.

몬스터는 공격 전 몸을 젖히거나 턱·팔·날개를 움직인다. 0.46초 후 사거리와 높이를 다시 확인하여 공격하므로 뒤로 물러나 피할 수 있다. 같은 동작은 한 번만 피해를 준다. 빙결은 이동과 공격 준비를 멈춘다. 피격 시 몸이 뒤로 반동한다. 사망 시 슬라임은 납작해지고, 정령은 회전하며 작아지고, 짐승과 골렘은 옆으로 쓰러진다. 약 5초 뒤 시체가 사라지며, 처치 40초 후 생물과 관절 자세를 복구한다.

`src/actors.js`에서 직접 만든 관절 그룹을 구동한다. 외부 모델, 모션 캡처, 애니메이션 팩은 사용하지 않는다.

## 전리품 수거와 저장

경험치와 처치 기록은 처치 즉시 적용한다. 기존 드랍 테이블에서 그때 한 번 추첨한 아이템과 골드를 주머니에 넣는다. 주머니에 다가가 **E**를 누르면 표시된 내용물 전체를 가방으로 옮긴다. 같은 주머니를 다시 받을 수 없다. 희귀/영웅 아이템이 들어 있으면 보라색 표시가 나타난다. 물 근처 주머니는 수면 높이에 둬서 수거할 수 있다.

미수거 주머니에는 시간 제한이 없으며 몬스터 재생성과 독립적이다. 자동 저장·내보내기·이어하기·플레이어 사망/부활에도 내용물과 위치를 유지한다. 이미 수거한 주머니는 저장 기록에서도 제거한다. 상자와 채집물은 기존처럼 E로 상호작용하는 순간 가방에 지급한다.

## 야영지 사람들과 의뢰

| NPC | 역할 | 의뢰 |
|---|---|---|
| 레아 (-4, 35) | 새벽 순찰대장 | 이끼 슬라임 3마리 처치 → 송곳니 3개 납품 |
| 엘리아 (6, 40) | 숲의 약초사 | 약초 4개 납품 → 연금술 1회 제작 |
| 토렌 (-7, 47) | 야영지 대장장이 | 아이템 2회 제작 → 고대 파편 2개 납품 |

NPC 머리 위와 미니맵의 **!**는 수락 가능한 의뢰, **?**는 보고 가능한 의뢰, **◇**는 진행 중 의뢰를 뜻한다. 가까이 다가가 E로 대화하고 수락한다. 화면 왼쪽은 보고 가능 의뢰를 우선 추적한다. J 기록창에서 모든 의뢰의 요구 조건과 보상을 확인한다.

처치·제작은 **의뢰 수락 이후**의 행동만 집계한다. 납품은 기존에 보유한 재료도 사용할 수 있고, 보고 시점의 가방 수량을 다시 확인한다. 보고 전에 재료를 제작에 사용하면 다시 모아야 한다. 완료 보고할 때만 요구 수량을 소모하고 경험치·골드·아이템 보상을 한 번 지급한다. 레아의 두 번째 의뢰는 Lv.3, 토렌의 두 번째 의뢰는 Lv.7과 선행 완료를 요구한다. 기존 자동 탐험 업적은 별도로 유지한다.

## 호환성과 실행

저장 슬롯 키와 파일 형식을 유지하고, 새 필드가 없는 v0.1/v0.2 저장 파일에는 비어 있는 의뢰·종별 처치·전리품 기록을 추가한다. 기존 캐릭터를 새로 만들 필요가 없다. 업데이트 전에 설정의 **저장 파일 내보내기**로 별도 백업할 수 있다.

기존 Codespaces 서버를 Ctrl+C로 종료한 뒤:

```bash
git switch codex/aetherwild-v0.1.0
git pull --ff-only
bash play.sh
```

소스가 바뀌면 실행기가 배포본을 갱신한다. Ports의 5173 페이지를 새로고침한다. 모든 신규 모델·모션·재질 셰이더는 코드에 포함되어 있으며 별도 에셋 다운로드는 필요 없다.

실행 결과와 검증 범위는 [VALIDATION.md](VALIDATION.md), 정확한 요구 수량과 보상은 [CONTENT_REFERENCE.md](CONTENT_REFERENCE.md)를 확인한다.
