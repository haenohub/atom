## 배포 빌드와 패키지

`npm run build` 및 소스/에셋 지문 검사를 사용한다. `/atom/` 하위 경로에 실제 `dist`를 배치하고 `production_smoke.py`에서 개발 접근점 없이 DOM과 키/마우스로 검증한다. ZIP은 CRC/SHA-256, 내장 빌드의 바이트 일치, 의존성 없는 새 폴더에서 `play.sh` HTTP 실행을 확인한 후 배포한다.

실제 배포 빌드의 `production_smoke.py`도 통과했다. 개발 접근점이 없고, 세이브5칸/화살 선택·최대 당김·발사/F1/장비 장착·해제/직접 걸어서 NPC 접근·E 대화·의뢰 수락/R 탑승·지상 하차·이전 시점 복원/탑승 중 F1 제한/방향+상승 동시 입력을 DOM과 실제 입력으로 확인했다. JavaScript·셰이더·이미지 오류는0개다.

GitHub Pages는 `.github/workflows/pages.yml`이 `codex/aetherwild-v0.1.0` 브랜치의 동일 소스를 검사·빌드·배포한다. 업로드 후 실제 Actions의 배포 완료 상태를 별도로 확인한다.
