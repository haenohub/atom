## 빌드와 배포 검증 방법

`npm run build`와 소스/에셋 지문 검사 후 `scripts/package-release.py`로 소스·에셋·배포 빌드를 함께 압축한다. ZIP CRC와 SHA-256을 확인한다. `node_modules`와 Git 데이터는 포함하지 않는다.

`production_smoke.py`는 개발용 접근점 없이 DOM과 실제 키/마우스 입력만 사용한다. 새 저장 칸 선택, 활 장전/최대 당김/발사, F1 양방향 전환, 장비 장착/해제, 능력치 버튼, 실제 걸어서 NPC 접근·E 대화·의뢰 수락을 확인한다. 중첩 경로에서 이미지 주소가 중복되지 않는지도 확인한다.

실제 실행 환경의 그래픽은 GPU·브라우저·품질 설정에 영향을 받는다. 이 검증은 상용 게임 수준의 실사 품질이나 모든 하드웨어의 성능을 보장하는 자료가 아니다.

## 최종 실행 패키지 확인

- ZIP을 `/tmp/aetherwild-v05-clean`의 새 폴더에 해제했다. `node_modules`가 없는 상태에서 소스 지문이 일치했고 `bash play.sh 4210`이 설치/재빌드 없이 실행되어 HTTP 200을 반환했다.
- 해제한 `aetherwild/dist`를 중첩 URL 경로에서 열어 `production_smoke.py`를 실행했다. 5개 저장 칸 중 2번에 궁수 생성, 활 스킬 선택·최대 당김·발사, F1 전환, 투구 해제/장착, 능력치 버튼, 실제 WASD로 레아 접근·E 대화·의뢰 수락이 통과했다. 개발 접근점은 없고 JavaScript/셰이더/이미지 오류가 없었다.
- 최종 단위 검사 117개와 공백 오류 검사를 재확인했다. 검증 기록 갱신 후 다시 압축한 ZIP의 CRC·SHA-256·빌드 지문을 확인하고, 최종 ZIP의 `src`/`public`/`dist`/실행 스크립트가 실제 브라우저에서 검사한 패키지와 동일한지도 비교한다.
